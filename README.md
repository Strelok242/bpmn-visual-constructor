# FlowCraft — визуально-графический конструктор BPMN

Учебный ИТ-проект по дисциплине «Проектная деятельность в ИТ». Вариант для фамилий с Ч до Щ: **«Разработка визуально-графического конструктора BPMN»**.

## Возможности

- Создание и перемещение четырёх типов объектов: начальное событие, задача, исключающий шлюз XOR, конечное событие.
- Соединение объектов направленными потоками управления; запрет нескольких некорректных типов связей.
- Редактирование названий элементов и процесса, удаление, отмена/повтор действий, масштабирование.
- Автосохранение в localStorage текущего браузера.
- Импорт/экспорт собственной модели JSON.
- Экспорт BPMN 2.0 XML с семантическими объектами, потоками и координатами BPMN Diagram Interchange.
- Встроенный пример бизнес-процесса «Обработка заявки клиента».

**Границы проекта:** это учебный прототип, а не полнофункциональный редактор BPMN 2.0.2. Здесь нет дорожек (lanes), подпроцессов, таймеров, сложных событий и проверки всех правил стандарта. XML доступен для экспорта; импорт BPMN XML не реализован. Импортируется JSON проекта.

## Запуск

Скачайте архив, распакуйте и перейдите в каталог проекта.

```bash
# Из корня проекта, если установлен Python 3
python -m http.server 8000
```

Откройте `http://localhost:8000`. На Windows вместо `python` может использоваться `py`:

```powershell
py -m http.server 8000
```

Это статическое веб-приложение. Дополнительные npm-пакеты для работы редактора не нужны. Используется браузер с поддержкой ES-модулей, SVG и localStorage.

## Как построить диаграмму

1. Нажмите «Пример процесса», чтобы увидеть готовую модель, или добавьте блоки из палитры.
2. Выберите инструмент «Поток управления» (`C`), затем щёлкните источник и целевой блок.
3. Выберите блок (`V`), чтобы переместить или переименовать его через инспектор.
4. Нажмите «Экспорт BPMN» для получения `.bpmn` или «JSON» для резервной копии.

Горячие клавиши: `1` — начало, `2` — задача, `3` — XOR, `4` — завершение, `V` — выделение, `C` — связь, `Delete` — удалить, `Ctrl+Z` — отмена, `Ctrl+Y` — повтор.

## Проверка

Требуется Node.js 20 или новее только для автоматических тестов:

```bash
npm test
```

Тесты не требуют установки сторонних зависимостей.

## Состав репозитория

- `index.html`, `styles.css` — интерфейс редактора;
- `src/model.js` — структура данных, ограничения и геометрия объектов;
- `src/app.js` — взаимодействия интерфейса с моделью;
- `src/bpmn-export.js` — экспорт BPMN XML;
- `tests/` — модульные тесты;
- `docs/` — иерархическая структура работ, роли, архитектура, сценарии проверки, порядок публикации;
- `evidence/` — реальные скриншоты работающего веб-приложения, если приложены к архиву.
