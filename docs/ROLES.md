# Категории пользователей и доступ к репозиторию

Роли определены для потенциальной учебной команды в организации GitHub. **Ниже проектная матрица прав, а не подтверждение, что такие пользователи были добавлены в реальный репозиторий.**

| Категория | Роль GitHub (организация) | Возможные действия |
|---|---|---|
| Руководитель/владелец | Admin | Доступ, настройки репозитория, ветки и правила |
| Ответственный за выпуск | Maintain | Управление проектом без доступа ко всем чувствительным настройкам |
| Разработчик | Write | Изменения, коммиты, push в разрешённые ветки, pull request |
| Рецензент/аналитик | Triage | Просмотр кода, работа с задачами/запросами, без права push |
| Наблюдатель/преподаватель | Read | Просмотр публичного проекта и истории изменений |

Для личного GitHub-репозитория права отличаются от организации: владелец управляет репозиторием, приглашённые сотрудники получают доступ согласно правилам личных репозиториев. Поэтому указанная схема применима в полной форме к **организационному** репозиторию.

Рекомендуется защищать ветку `main`, вносить изменения через `feature/*`, выполнять тесты перед слиянием и проверять pull request.
