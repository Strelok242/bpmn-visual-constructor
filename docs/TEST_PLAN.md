# План и протокол проверки

## Автоматическая проверка

Команда `npm test` проверяет: создание всех типов, ограничения связей, дублирование потока, корректность демомодели, несуществующие ID, повторяющиеся ID, BPMN XML, экранирование спецсимволов, геометрию соединений.

## Сценарии браузерной приёмки

| ID | Действия | Ожидаемый результат |
|---|---|---|
| E2E-01 | Открыть проект и нажать «Пример процесса» | 7 элементов, 6 потоков |
| E2E-02 | Выбрать задачу и нажать на свободное поле | 8 элементов |
| E2E-03 | Выбрать два блока в режиме «Поток управления» | Новый направленный поток |
| E2E-04 | Выделить задачу, изменить имя | Новый текст в блоке |
| E2E-05 | Переместить блок | Координаты изменены |
| E2E-06 | Экспортировать BPMN XML | Скачан `.bpmn` |
| E2E-07 | Экспортировать JSON, импортировать обратно | Модель восстановлена |
| E2E-08 | Перезагрузить страницу | Модель сохранена локально |

Скриншоты в `evidence/` служат иллюстрацией результатов реального браузерного исполнения проекта, не подтверждают работу на Windows пользователя или публикацию на GitHub.
