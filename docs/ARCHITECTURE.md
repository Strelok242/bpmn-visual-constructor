# Архитектура

```
Пользователь
   │
   ▼
index.html + styles.css       интерфейс, доступные команды
   │
   ▼
src/app.js                   отображение SVG, события, автосохранение
   ├────────► src/model.js   структура объектов, валидация, геометрия
   └────────► src/bpmn-export.js   преобразование модели в BPMN XML
                        │
                        ▼
              файл bpmn-process.bpmn
```

Модель хранит `nodes` (id, type, x, y, name) и `flows` (id, source, target). Элемент `type` ограничен четырьмя поддерживаемыми типами. `model.js` не зависит от браузера; поэтому он тестируется средствами Node.js. `app.js` создаёт SVG DOM и отображает модель без HTML-инъекций из пользовательских названий (используется `textContent`).

Данные JSON сохраняются локально браузером. BPMN XML содержит префиксы `bpmn`, `bpmndi`, `dc`, `di`. Этот формат экспортируется без BPMN-движка исполнения. XML предназначен для визуализации и последующей обработки в совместимых инструментах; полная интероперабельность с любыми редакторами не гарантирована.

**Риски и меры:** потеря браузерных данных → регулярный экспорт JSON; некорректный JSON → проверка структуры; неподдерживаемые элементы BPMN → явно документированные границы; конфликт команды → Git ветки и проверка перед слиянием.
