# Техническое задание на учебный прототип FlowCraft

**Назначение:** создание и редактирование небольших диаграмм бизнес-процессов с базовыми элементами нотации BPMN. Целевая аудитория: обучающиеся, аналитики начального уровня, разработчики учебных прототипов.

## Функциональные требования

| ID | Требование | Проверка |
|---|---|---|
| F-01 | Создание стартового события, задачи, XOR-шлюза и конечного события | Визуально и тесты |
| F-02 | Соединение объектов направленным потоком | Визуально и тесты |
| F-03 | Перемещение объектов по SVG-полотну | В браузере |
| F-04 | Редактирование названия элемента и процесса | В браузере |
| F-05 | Удаление элемента вместе с его связями | В браузере |
| F-06 | Отмена и повтор действий | В браузере |
| F-07 | Автосохранение в localStorage | Перезагрузка вкладки |
| F-08 | Импорт и экспорт JSON | Круговой прогон |
| F-09 | Экспорт BPMN XML с координатами элементов | Модульные тесты и XML-парсер |
| F-10 | Заготовка демонстрационного процесса | В браузере |

## Нефункциональные требования

- Запуск без обращения к серверным API и без внешних библиотек.
- Поддержка актуальных настольных браузеров с SVG/ES-модулями.
- Русскоязычный интерфейс и предупреждения об ошибках ввода.
- Валидация импортируемой JSON-модели; лимит 200 блоков и 500 потоков.
- Не хранить пароли и персональные данные в модели; не включать секреты в репозиторий.

## Критерии приёмки

Пример модели отображается в браузере; можно добавить задачу, связать её с другой задачей, переименовать и переместить; JSON можно сохранить и восстановить; XML содержит узлы, связи и геометрию. Автотесты проходят без ошибок. Внешняя публикация GitHub проверяется отдельно.

## Ограничения

Полное соответствие всей грамматике и исполнимой семантике BPMN 2.0.2 не заявляется. Отсутствуют совместное редактирование, серверное хранение и серверные роли. Пользовательские права описаны для командного управления GitHub, а не реализованы в клиентском приложении.
